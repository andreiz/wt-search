# M1 Plan 3 — Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Listeners can search the seed corpus on staging from a web page: type a query, get result cards with highlighted excerpts and play buttons that open YouTube, Apple or Spotify at the moment, expand the transcript around a hit, and report a transcript error or send feedback. The page is served by the same Worker as the API.

**Architecture:** `web/` is a Vite + TypeScript + Preact app built to static files in `web/dist`. The Worker serves them as **static assets** (spec §5.1): `run_worker_first: ["/api/*", "/robots.txt"]` sends the API and robots.txt to the Worker's code, and every other path is a static file that costs no Worker invocation. One build serves every environment; what differs per environment comes from `GET /api/info` at runtime. The app is one page whose whole state is in the URL; logic lives in small pure modules with unit tests, and the components are thin.

**Tech Stack:**
- Web: Preact 10, Vite with `@preact/preset-vite`, TypeScript (strict, `noUncheckedIndexedAccess`, the same major as `worker/`), Vitest 4 with happy-dom and `@testing-library/preact`, Playwright (`@playwright/test`) with `@axe-core/playwright`. No router, no state library, no CSS framework. Use current stable versions and commit `package-lock.json`; install with `npx npm@11 install …` (npm 10.9 crashes on vitest 4.1, handoff "Worker test pointers").
- Worker: plan 2's stack. No new runtime dependencies.
- External: Cloudflare Turnstile (Managed mode), loaded only when a form opens.

**Spec:** `docs/superpowers/specs/2026-10-04-wood-talk-search-design.md` §5 (all of it, revised 2026-10-08), §4.3 (`year:A-B`), §4.4 (`folded`, `/api/info`, feedback reports), §4.8 items 5–6, §7.1. Design brief: `docs/design/BRIEF.md` (copy for every state, sample data). **Design (delivered 2026-10-09):** `docs/design/system/`: `README.md` has every measurement and interaction, `tokens.css` the tokens, the `.dc.html` mocks each component and state (open them through a local HTTP server; their viewer, `support.js`, renders them with React from unpkg, which says nothing about our stack). ## Global Constraints

- **No host anywhere in `web/`.** The app calls relative `/api/...`; links come from the API (`episode.links`, per-chunk `links`); the frontend never builds a play link (spec §4.6).
- **Nothing per environment in `web/dist`.** No `VITE_*` values; the Turnstile site key comes from `/api/info`.
- **CSP-clean code:** no inline `<script>`, no `style="…"` attributes and no Preact `style={…}` props (CSP `style-src 'self'` blocks them; use classes and CSS custom properties set from stylesheets). The only third-party origin is `https://challenges.cloudflare.com`.
- **Types:** the API's response types are imported **type-only** from `worker/src/` (`import type { … } from "../../worker/src/search"`), never copied. If a type the app needs isn't exported, export it from the Worker.
- **Highlight ranges are UTF-16 offsets** (JavaScript string indices); slice `text` with them directly.
- **Accessibility is part of every component task,** not a final pass: real buttons and links with names, a list for results, visible focus, `prefers-reduced-motion`, WCAG AA contrast (the design's tokens claim AA in both themes; Task 14's axe run checks).
- **Copy** comes from `docs/design/BRIEF.md` §4.5 and spec §5.6; when they differ, the spec wins.
- **Look** comes from `docs/design/system/`: build each component to its mock and the README's measurements, in Preact with classes and the tokens (the mocks' inline styles are references, not code to copy). Where the mocks contradict spec §5, the spec wins (its §5.7 lists the known deviations: no "Sponsor read" label, no `include:ads` hint, no `years` URL parameter).
- Worker changes follow plan 2's rules: test-first, `cd worker && npm test && npx tsc --noEmit`; check the test count after each run (a lone surrogate in a test name drops a file silently).
- Commit straight to `main`, one commit per task. Every commit message ends with the repo's attribution lines, if the session provides them.

## Decisions this plan makes (from the brainstorm, confirmed by the maintainer 2026-10-08)

1. **Static assets on the API Worker**, not Pages (spec §5.1). `assets` is an inheritable key, so it is set per environment, not at the top level, which stays the local/test config. A local-only `env.e2e` (D1 + assets, never deployed) runs the smoke test.
2. **`year:2015-2020`** is parser sugar for `after:2014 before:2021` (spec §4.3). No API parameter, no cache-key change, no Vectorize change.
3. **`folded` on every result** (chunk ids), replacing `debug.folded`; `wts search --debug` reads the new field.
4. **`/api/info`**, edge-cached by `corpus_version` with the search cache's TTL var.
5. **Reports without `chunk_id` are feedback**; reports accept the request's own origin.
6. **`/robots.txt` by `WTS_ENV`**: production allows the pages and disallows `/api/`; every other environment disallows everything.
7. **Title stripping mirrors the pipeline's `split_title`** (`pipeline/src/wts/stems.py`) in `web/src/lib/title.ts`, with a shared fixture both halves check (like `worker/test/fixtures/word_times.json`).
8. **Grouping neighbours** *(maintainer, 2026-10-09)*: consecutive results from one episode share a card header ("N matches"); the API's order is never changed (spec §5.3).
9. **Related hits fold at the end of each page** *(maintainer, 2026-10-09)*: keyword hits first, then "Show N related passages"; a page with no keyword hits shows its related hits open under "No exact matches —" (spec §5.3, §5.6).
10. **Source Serif 4 is self-hosted** (400 and 600, Latin subset, woff2, from the `@fontsource/source-serif-4` npm package), not loaded from Google Fonts; CSP `font-src 'self'` (spec §5.1, §5.7).

## Review Focus

1. **The CSP actually holds.** A strict CSP that the app quietly violates shows up as a blank page or a dead Turnstile in production only. Playwright fails any test that logs a CSP violation (`securitypolicyviolation` listener), and the smoke run (Task 15) serves the real `_headers`.
2. **Stale answers.** A slow first search must never overwrite a newer one. Every fetch carries an `AbortController`, and the app also ignores any answer whose request isn't the latest (Task 7).
3. **URL ↔ state round trip.** Back and Forward, a shared link and a reload must all show the same search. Defaults are omitted from the URL, and unknown values fall back like the API does (Task 6).
4. **The year chip and the box never disagree.** The chip shows the box's effective range; setting it rewrites only the year tokens (Task 8).
5. **Turnstile lifecycle.** The script loads once, the widget renders when a form opens and is removed when it closes, and after any failed send it is reset before the next try (spec §4.4; Task 13).
6. **No host leaks.** A test greps `web/dist` after a build for `workers.dev`, `10fathoms` and `localhost` (Task 4).
